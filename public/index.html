Importer un fichier

Un seul formulaire est utilisé pour cette crise. Le fichier doit s'appeler exactement :

  • Formulaire relogement → relogement.xlsx

Tout autre nom est refusé et aucune donnée n'est importée. La casse n'a pas d'importance (Relogement.xlsx convient), et les fichiers .xls sont également acceptés. Le fichier sorti de Forms porte un nom qui change à chaque export : il faut donc le renommer avant de le déposer.

Un même fichier peut être réimporté sans risque : seules les réponses qui ne sont pas déjà en base sont reprises.
